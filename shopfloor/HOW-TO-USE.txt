FLOORLINE — so nutzen Sie diesen Rechner

Sie müssen keine Ordner öffnen und nichts tippen.

START
  Floorline auf dem Desktop doppelklicken.
  Ein paar Sekunden warten. Die App öffnet sich im Vollbild.

STOPP
  Oben auf Ende klicken oder Esc drücken.
  Dann Floorline beenden auf dem Desktop doppelklicken.

ZUM ERSTEN MAL
  Auf „Demo-Produktion laden“ klicken oder XML-Dateien aus der Freigabe wählen.

VOLLBILD
  Floorline öffnet sich von selbst im Vollbild.
  Wenn Windows oder der Mac-Schreibtisch dahinter sichtbar ist, oben auf Vollbild klicken.

ANDERER RECHNER
  Oben auf Freigabe klicken und dieser Person die Adresse schicken.
  Sie kann Windows, einen Mac oder Linux nutzen.

Wenn Floorline nicht öffnet, den Installer einmal doppelklicken
(install-windows.cmd oder install-macos.command) und Floorline erneut versuchen.
